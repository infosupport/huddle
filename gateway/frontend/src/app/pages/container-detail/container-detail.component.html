De container heeft twee gebruikers: vscode (jouw normale werkgebruiker, zonder sudo) en noot (beheerdersgebruiker met sudo-rechten). Wissel naar noot alleen wanneer je iets als root moet uitvoeren — alle sudo-acties worden automatisch bijgehouden in het audit log.

Hoe wissel je van gebruiker?

# Wissel naar noot (heeft sudo-rechten)
su - noot

# Voer vervolgens commando's als root uit
sudo apt install <pakket>
sudo systemctl restart <service>

# Wissel terug naar vscode
exit

# Controleer recente sudo-acties
sudo cat /tmp/sudo-audit.log

Alle sudo-acties verschijnen ook in de Audit Logs pagina gefilterd op jouw container.
