Part 1 — Get it working

Latest release STABLE · GET THE BASICS WORKING

Install the CLI, connect to an empty container and watch how firewall requests surface and get approved. Then bring your own project in and start it inside the dev container.

Setup

Two commands on your own machine. The CLI is the host runner — it starts the gateway and holds an ephemeral operator token.

$ npm install -g @infosupport/huddle-cli
$ huddle init

How it fits together

Everything your dev environment sends outward passes through the gateway. The gateway is what enforces the rules; nothing reaches the internet around it.
